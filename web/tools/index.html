native desktop tools

aicmd · jptxt · mdview

Three small tools that work together. All are native C++ with no Electron, browser engine or runtime to install, and all are free under the MIT license. Early versions; feedback welcome on GitHub.

aicmd

v0.2.0 · file commander · Windows

A keyboard-first two-panel file manager in the style of Total Commander and Midnight Commander.

  • Local folders and SSH/SFTP servers in the same panels, with tabs
  • Copy, move, rename, new folder and Recycle Bin delete. Existing files are never overwritten
  • Alt+F7 search that streams results while it walks huge trees
  • ZIP, JAR, TAR and TAR.GZ archives open like folders (read-only)
  • F3/F4 open files in jptxt; Space plays media with the built-in aiview player when libmpv is present
Download for Windows x64 (zip) Source

Portable: unzip anywhere and run aicmd.exe. Not code-signed yet, so Windows SmartScreen may warn on first start. Install jptxt (below) for F3/F4; aicmd finds it automatically.

jptxt

notepad · Windows, macOS, Linux

A super-fast notepad: tabs, syntax highlighting, regex search and a hex view for binaries. Opens 100 MB+ files in tens of milliseconds.

Windows (PowerShell)

irm https://whatamieatingtoday.com/app/jptxt/install.ps1 | iex

macOS / Linux

curl -fsSL https://whatamieatingtoday.com/app/jptxt/install.sh | bash

mdview

v0.3.0 · Markdown viewer · Windows

A fast Markdown viewer with GitHub-style tables, task lists and code blocks. It draws the page itself, so it needs no WebView2 or browser, and it opens a 20 MB file in about a tenth of a second.

  • mdview.exe: a standalone viewer
  • mdview.wlx64: a lister plugin for Total Commander and Double Commander. Open the zip in Total Commander and it offers to install itself
